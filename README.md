# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer. It runs as a small Python program and writes the line to `entry.txt`.

Entry for the make.fun bounty [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

## Run

```sh
python3 main.py
```

It writes one line to `/output/entry.txt`, or to `$OUTPUT_DIR/entry.txt` when that is set.
